## 1. 设计语言定位

**Apple 原生系统风格** —— 清爽、克制、精致。

| 要素 | 取向 | 明确避免 |
|---|---|---|
| 布局 | 大标题 + 分组卡片 + 充足留白 | 密集表格、拥挤边框 |
| 层级 | 靠留白与明度差，而非重阴影 | 浓重投影、多层嵌套卡片 |
| 色彩 | 大面积中性色 + 单一强调色 | 多彩、高饱和堆叠 |
| 圆角 | 大圆角、连续曲率感 | 直角、极小圆角 |
| 动效 | 短、跟手、有物理感 | 长动画、弹跳过度 |
| 玻璃 | 少量、重点位置 | 全页面铺满 |

## 2. 设计令牌（P02 落地为代码常量）

> ⚠️ 以下为**规范定义**，具体数值在 P02 结合实际渲染效果确定。
> 本阶段给出结构，避免 P02 时临时拍脑袋。

### 2.1 色彩

| 令牌 | 用途 | 说明 |
|---|---|---|
| `BgBase` | 页面背景 | 浅色模式极浅灰白；深色模式近黑但非纯黑 |
| `BgElevated` | 卡片背景 | 与背景形成轻微明度差 |
| `BgGlass` | 玻璃层底色 | 半透明 + 模糊，依赖设备能力 |
| `TextPrimary` | 主要文字 | 标题、数据值 |
| `TextSecondary` | 次要文字 | 说明、时间戳 |
| `TextTertiary` | 弱化文字 | 免责声明、来源 |
| `Accent` | 强调色 | 主操作、选中态 |
| `StatusOnline` / `StatusInGame` / `StatusOffline` / `StatusUnknown` | 状态语义色 | ⚠️ 必须配合**图标或文字**，不能只靠颜色区分（无障碍） |
| `Danger` | 错误 | 错误态、警告 |
| `Divider` | 分隔线 | 极弱对比 |

**硬性要求**：
- 文字与背景对比度需满足无障碍可读性；玻璃效果下必须回退到足够实的底色。
- 状态不能仅用颜色表达（色盲可读性）。

### 2.2 字体与层级

| 令牌 | 用途 |
|---|---|
| `DisplayLarge` | 首页大标题、密码大字 |
| `TitleLarge` / `TitleMedium` | 卡片标题、页面标题 |
| `BodyLarge` / `BodyMedium` | 正文、列表项 |
| `LabelMedium` | 标签、分类 |
| `Caption` | 时间戳、来源、免责声明 |

> 中文需显式指定中文字体回退，避免粗细与字形不一致（P02 验证）。

### 2.3 圆角

| 令牌 | 用途 |
|---|---|
| `RadiusCard` | 卡片（大圆角，风格核心） |
| `RadiusButton` | 按钮 |
| `RadiusChip` | 标签、筛选 |
| `RadiusSheet` | 弹层 |

### 2.4 间距

4dp 基准栅格：`XS=4` / `S=8` / `M=12` / `L=16` / `XL=24` / `XXL=32`。
页面左右安全边距统一，卡片内部 padding 统一。

### 2.5 触控与反馈

- 最小触控目标 **≥ 48dp**。
- 所有可点元素必须有按下反馈（缩放或明度变化）。
- 「减少动态效果」开启时：关闭玻璃动画与转场，**保留**必要的状态切换提示。

## 2.6 ★ P02 实测修正的设计令牌（都来自真实截图，不是估算）

以下数值在 P02 落地后由**实机截图**暴露问题并修正，写回此处以免再次踩坑。

| # | 令牌 / 规则 | 原值 | **实测修正值** | 触发问题 |
|---|---|---|---|---|
| 1 | `UbSize.toolCardHeight` | 108dp | **132dp** | 卡片内容实为 `pad16+icon44+gap8+title24+gap2+caption17+pad16 = 127dp`，108dp 会把描述文字裁掉 |
| 2 | `UbSize.bottomBarReserved` | （无） | **112dp** | 新增令牌。悬浮底部导航会盖住可滚动内容的最后一行，各页底部必须留出该占位 |
| 3 | `UbColors.bgGlass`（浅色） | `0xCCFFFFFF` | **`0xE6FFFFFF`** | 玻璃不透明度不足时，其上的图标与文字对比度过低 |
| 4 | `UbColors.bgGlass`（深色） | `0xB31A1C20` | **`0xE61A1C20`** | 同上 |
| 5 | 底部导航未选中项颜色 | `textTertiary` | **`textSecondary`** | 叠加玻璃后 `textTertiary` 几乎不可见 |
| 6 | 底部导航选中态强化 | 仅颜色 | **颜色 + `SemiBold` 字重 + 药丸衬底** | 无障碍：状态不可仅靠颜色表达 |

### ★ Tab 栏的苹果观感要素（依据用户提供的参考图落地）

参考图的关键特征拆成三条，缺一条都会"不像"：

| # | 要素 | 实现 | 实测踩坑 |
|---|---|---|---|
| 1 | **通透磨砂材质** | `UbGlassStyle.Regular`：底色不透明度 0.72 + 模糊 26dp | 早期用不透明白卡，显得"廉价" |
| 2 | **选中项药丸高亮衬底** | `UbColors.tabPill` + 弹簧动画滑动 | ⚠️ **不能用纯白**：玻璃材质本身已近白，同色会导致药丸完全看不见。必须略深于材质（浅色 `#E3E7EC` / 深色 `#3A3F47`） |
| 3 | **材质顶部高光** | `UbColors.glassHighlight` + 垂直渐变覆盖层 | 模拟 iOS 材质的镜面边缘，是"像不像"的关键细节 |
| 4 | 标签只在选中项显示 | 未选中只留图标 | ⚠️ **必须补 `contentDescription`**：否则屏幕阅读器与 `uiautomator` 都无法识别未选中项，点击目标也会消失（实测回归） |

### ★ Tab 栏实现的三个硬约束（全部来自实测）

1. **药丸偏移的坐标基准**：`BoxWithConstraints` 上的 `padding` 会改变子项坐标基准，
   而 `maxWidth` 是**填充前**的宽度 → 药丸会算错宽度并偏位。
   **padding 一律放到内部 `Row` 上**，药丸偏移用 `horizontalPad + itemWidth * position`。
2. **semantics 必须在 clickable 之前**：反过来的话 `clickable` 会成为语义树的叶节点，
   `contentDescription` 与 `selected` 不会被合并进去 —— 实测表现为 dump 里 `clickable=false`。
3. **`selected = ...` 有名称歧义**：语义属性 `selected` 与外层同名局部变量冲突时，
   裸赋值无法解析。用 `import androidx.compose.ui.semantics.selected as semanticsSelected` 起别名。

### ★★ 玻璃实现的两条硬约束（血泪）

> 这两条是把 `Modifier.blur` 用错两次、看了三轮截图才定位的。

1. **模糊只能作用于背景层，绝不能加在容器上。**
   加在容器上时，子内容（图标、文字）会**一起被模糊**，底部导航文字几乎不可见 —— 直接违反「玻璃之上承载文字必须清晰」的可读性红线。
   正确结构：外层容器（clip + border）→ **背景层（blur + 半透明色）** → **内容层（不模糊）**。

2. **背景层必须用 `Modifier.matchParentSize()` + `BlurredEdgeTreatment.Rectangle`。**
   若用 `fillMaxSize()` + `BlurredEdgeTreatment.Unbounded`：
   - `Unbounded` 会为了让模糊边缘自然而**外扩绘制范围**；
   - 叠加 `fillMaxSize()` 后，玻璃层会**膨胀到整个屏幕**，把页面内容全部盖住。
   - `matchParentSize()` 让背景层跟随内容尺寸（不反向撑开父容器），`Rectangle` 则不外扩。

相关实现集中在 `core/design/UbGlass.kt`，**所有玻璃效果必须经 `UbGlassSurface`**，
页面不得直接调用 `Modifier.blur` —— 这样"可独立降级或关闭"才始终成立。

## 3. 页面原型（8 类，设计稿 P02 要求）

### 3.1 首页 HomeScreen

```
┌─────────────────────────────────────┐
│  UtilityBox                    [⚙]  │  ← 大标题 + 设置入口
│  三角洲行动                          │  ← 当前游戏（未来为选择器）
│                                     │
│  ┌─────────────┐  ┌─────────────┐  │
│  │  [icon]     │  │  [icon]     │  │  ← 工具网格（注册表驱动）
│  │  今日密码    │  │  物品物价    │  │
│  │  每日地图密码 │  │  查询实时价格 │  │
│  └─────────────┘  └─────────────┘  │
│  ┌─────────────┐                    │
│  │  [icon]     │                    │
│  │  好友状态    │  ← 若数据源不可用  │
│  │  [不可用]    │     卡片显示灰态   │
│  └─────────────┘                    │
│                                     │
│  ─────────────────────────────────  │
│  数据来源：社区接口 · 更新 10 分钟前  │  ← 数据状态摘要
└─────────────────────────────────────┘
        [ 首页 ]    [ 设置 ]           ← 底部悬浮导航（Liquid Glass）
```

**要点**
- 工具卡片内容**完全来自 `ToolRegistry`**；首页不出现任何具体工具名。
- 数据源不可用的工具**仍然显示**（让用户知道有此功能），但标记状态且点击后说明原因。
- 底部导航是 Liquid Glass 的首要应用位置。

### 3.2 工具列表 ToolsScreen

按 `ToolCategory` 分组：游戏数据 / 价格 / 实用 / 个人。
每项显示名称、描述、状态；停用的工具置灰并说明。

```
│  │  零号大坝                    │   │
│  │                             │   │
│  │      X7K9-2M4P              │   │  ← 玻璃重点卡片 + 密码大字
│  │                             │   │
│  │              [ 复制 ]        │   │
│  └─────────────────────────────┘   │
│  ┌─────────────────────────────┐   │
│  │  长弓溪谷      Q3W8-1Z6N      │   │
│  └─────────────────────────────┘   │
│                                     │
│  来源：社区接口 · 更新 08:12          │
└─────────────────────────────────────┘
```

**四态表现（强制）**

| 状态 | 界面表现 |
|---|---|
| 当天有效 | 正常显示，日期为今天 |
| 过期缓存 | 卡片置灰 + 顶部横幅「这是 **X月X日** 的数据，今日密码尚未更新」 |
| 暂无数据 | 空态「今日密码尚未发布」+ 说明来源未更新 |
| 请求失败 | 错误态 + 错误类型 + 重试按钮 |

> **红线**：过期数据**绝不**以今日数据的样式呈现。

**图表约束**
- 只画**真实存在的数据点**；`count == 0` 的日期**留空断线**，不插值。

- 0 个有效点时：显示空态「暂无历史价格记录」。

### 3.8 空数据与错误状态（统一组件）

| 组件 | 用途 | 必须包含 |
|---|---|---|
| `UbLoading` | 加载中 | 骨架屏，不用空白页 |
| `UbEmpty` | 空数据 | 为什么空 + 下一步建议 |
| `UbError` | 错误 | 错误类型文案 + 重试按钮 |
| `UbStaleBanner` | 陈旧数据 | 原始抓取时间 + 刷新按钮 |
| `UbMockBadge` | 模拟数据 | 「模拟数据」标记（`PROJECT_RULES` §8） |

**错误文案映射**

| 错误类型 | 文案 | 操作 |
|---|---|---|
| 无网络 | 网络不可用，请检查连接 | 重试 |
| 超时 | 请求超时，服务可能繁忙 | 重试 |
| 服务端错误 | 数据服务暂时不可用 | 稍后重试 |
| 鉴权失败 | 访问凭据无效或已过期 | 前往设置 |
| 数据格式错误 | 数据格式异常，可能接口已变更 | 反馈 + 重试 |
| 业务错误 | 显示数据源返回的 message | 重试 |
| 数据源不可用 | 该功能当前无可用数据源 | 查看数据源状态 |

## 5. Liquid Glass 应用规范

### 5.1 应用位置（少而精）

| 位置 | 用 | 理由 |
|---|---|---|
| 底部悬浮导航 | ✅ | 悬浮于滚动内容之上，层次最明显 |
| 密码大字卡 / 价格主卡 | ✅ | 单页视觉焦点 |
| 列表项卡片 | ❌ | 滚动性能与可读性风险 |
| 正文背景 | ❌ | 可读性红线 |

### 5.2 必须支持降级（设计稿硬性要求）

| 触发 | 行为 |
|---|---|
| 用户在设置中关闭 | 全部玻璃效果退化为不透明卡片 |
| 设备能力不足（P01 确定判定方式） | 自动降级，并在设置页说明原因 |
| 「减少动态效果」开启 | 关闭玻璃动画，保留静态半透明 |

**降级后必须保证**：功能完整、文字可读、滚动流畅。
**不允许**为了视觉效果牺牲可读性、无障碍支持、滚动性能或基础功能。

### 5.3 待 P01 验证的技术问题

见 `docs/risks.md`。P00 阶段**不选定**具体实现方案，避免在未验证的前提下写死依赖。
